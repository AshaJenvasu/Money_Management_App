# 💰 Money Management App

## 📌 Project Overview

**Status:** 🚧 In Development

A full-stack personal finance application for managing wallets, transactions, and investments.

This project is built end-to-end to practice backend development, database design, API development, authentication, and financial data handling using Go and PostgreSQL.

---

## ✨ Planned Features

* 🔐 Multi-user authentication using JWT + bcrypt
* 💳 Multiple wallets with cash and investment wallet types
* 💸 Income and expense tracking with live balance calculation
* 📈 Investment tracking using the Average Cost method
* 📊 Support for cryptocurrency and stock assets

## 🎯 Project Goal

The main goal of this project is to gain practical experience building a full-stack application from database design to backend API and frontend integration.

It is also intended as a portfolio project to demonstrate practical skills in **Go, PostgreSQL, backend architecture, API development, and database design**.
